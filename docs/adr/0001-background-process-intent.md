# 按用户意图区分后台进程与前台启动

Skill Deck 将内部枚举、计算和有界业务操作统一视为后台进程（Background Process），由应用监督且不得自行创建可见界面；只有用户明确要求打开资源或外部应用时，才使用允许显示窗口的前台启动（Foreground Launch）。该边界集中管理 Windows 等平台的进程界面策略，但不统一接管各业务进程的超时、取消、输入输出、重试或错误转换，避免 WSL、Git 和未来调用点各自复制平台参数，也避免形成一个混合多种执行协议的通用执行器。Rust 静态检查默认禁止直接构造系统进程，统一边界、前台启动和测试夹具只能在局部说明原因后豁免。
