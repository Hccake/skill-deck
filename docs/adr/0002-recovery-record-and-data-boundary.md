# 恢复记录与恢复数据用于保护受保护写入的一致性

恢复数据只保存受保护写入的一致性证据。任务进入受保护阶段后，系统仅在无法确认 Skill 目录、Agent 专用安装项和相关 lock 是否一致时保留恢复记录；其他失败由原工作流即时反馈。

这项边界既保护文件安全，也让恢复入口专注于处理无法确认的一致性问题。产品具备可验证的自动事务恢复能力，或者产生正式的错误留存需求后，再重新评估恢复数据的范围。当前行为由[执行与恢复](../execution-and-recovery.md#恢复记录与恢复数据)和[产品行为与交互](../product.md#处理需要检查的写入结果)负责说明。
