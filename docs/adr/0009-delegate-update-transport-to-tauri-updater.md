# 应用更新传输行为交给官方 Tauri Updater

Tauri Updater 插件负责 endpoint 顺序、域名解析、重定向、下载、签名验证和安装。Skill Deck 创建 Updater 对象时只把当前 Direct 或 Custom Proxy 设置映射到官方插件，并维护运行许可、期望版本确认、进度、取消窗口和操作总时限；客户端不增加 host allowlist、自定义重定向、读取停滞或响应大小限制。

这项边界避免重复实现或收紧官方行为，同时保留本地产品需要的代理和交互语义。官方插件不再提供所需的代理、取消、签名或平台安装能力，或者其默认传输行为出现已经证实且无法由上游解决的问题时，再重新评估。当前行为由[系统架构](../architecture.md#外部网络访问)、[产品行为与交互](../product.md#关于与应用更新)和[测试与验证规范](../testing.md#后端测试)负责说明。
