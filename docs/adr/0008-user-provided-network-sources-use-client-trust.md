# 用户提供的网络 Skill 来源采用本地客户端信任模型

用户主动输入的 HTTP 或 HTTPS Well-known Skill 来源属于本次来源获取的授权范围，可以指向公开网络、本机或局域网。Skill Deck 使用 HTTP 客户端的正常域名解析和重定向行为，不增加服务端 SSRF 模型中的 DNS 公私网分类、地址固定、host allowlist 或同源限制；来源内容仍需通过格式、摘要、大小和解包校验。

这项取舍使轻量本地工具能够访问用户自己的开发服务和内网来源，并避免维护跨平台 DNS 安全推断。应用开始加载不受用户控制的远程页面、代用户访问未明确选择的地址，或者网络响应能够把本机数据发送给无关目标时，必须重新评估这项边界。当前行为由[产品行为与交互](../product.md#代理设置)、[系统架构](../architecture.md#外部网络访问)和[测试与验证规范](../testing.md#http时间与外部进程)负责说明。
