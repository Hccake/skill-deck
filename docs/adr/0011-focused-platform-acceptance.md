# 高层验证聚焦可维护的平台证据

Skill Deck 保留三平台 compile、unit、adapter 和 contract 测试，但不建设三平台完整 GUI E2E、真实 WSL 发行版 acceptance 或相关 artifact 系统。WSL 支持边界由跨平台协议测试、ShellCheck 和 Linux 上真实执行 bundled shell 固定；实际发行版排查可以作为问题诊断，但不成为仓库门禁。低频 started-app smoke 聚焦主发布平台的 loader、窗口、plugin、HTTP、外链和 Wizard 关键旅程。没有实际执行能力的 workflow 不是质量门禁，应删除而不是长期保留形式入口。
